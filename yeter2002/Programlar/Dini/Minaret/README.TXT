This is the README file included with Minaret for Windows.

The package contains the following files, which should be kept
in a single directory.

README  -  This file
MINARET.EXE  -  The Minaret program
MINARET.INI  -  Initialization file
GAZETTE.DTA  -  The gazetteer file for Minaret.  .
MINARET.DOC  -  Instructions on using the program
CMDIALOG.VBX  -  File needed by Minaret

To run Minaret, you also need to have a file called
VBRUN300.DLL in your Windows Systems directory, typically
called C:\WINDOWS\SYSTEM.  This file can be found on many
bulletin boards that carry Windows software.  If you can't get
it any other way, then request it in an e-mail to
abdali@netcom.com.  You may like to move CMDIALOG.VBX to the
Windows System directory also.

Minaret can be run by double-clicking on MINARET.EXE in the
Windows File Manager.  There is no Online Help in the present
version.  But you can browse the documentation by choosing Open
from the File menu and selecting MINARET.DOC.
.   
The gazetteer file contains geographical data for a number of
cities.  It gets updated by the program if you add or delete
cities, or modify the data stored about them.

Please remember that Minaret is a shareware program.  This means
that you are free to try it out and distribute its unmodified,
complete copy to others.  But if you decide to keep it, then you
should send the shareware fee of $10 to the author.

A Macintosh version of Minaret is also available.
