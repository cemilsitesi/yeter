  You can control the worm by using cursor keys and your mission is to try  1/8

  to eat as many pizzas as possible. (Player two keys are Z and C)

 

  Write PWORM ? to find out the game options / parameters.

 

  If the game halts on your machine, first disable sound system using parameter

  /N (I dont know how well does the Midas sound system work)

 

                   !!! IMPORTANT, IF SOUND DOES NOT WORK !!!

 

  Currently known bugs are that this version of midas sound system won't work

  with SB16, AWE, PAS16 soundcards. So don't wonder if you don't hear any sound.
