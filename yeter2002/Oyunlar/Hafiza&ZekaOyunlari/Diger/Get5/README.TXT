THE GAME

     The aim of this game is to place 5 of your `marbles` in a row, horizontal,
     vertical or diagonal.Your opponent is the computer who obviously also 
     tries to place 5 of his pieces in a row and win himself.

     You can move around on the board with your mouse. Select any of the empty
     fields and place one `marble` on it by pushing the left mouse button. 
     After you made your move it`s the computer`s turn, who tries to block you. 
     If you click on an occupied field, you will see the field where the last
     move was made to! 

     When you do well, you receive points and will be placed in the high 
     scoring table. But you can earn even more points by winning not only
     one match, but a series of matches. This will increase your score. 
     But if you loose, the series ends and you have to start over.



THE MENU
     
     Scroll a list of players by clicking with your left mouse button on the
     name or type in a new player.

     Click on `sound`, to switch sound on or off.

     Click on `level` to chose one of three.
     Level 1 is easy, level 3 is strong. The higher the level, the more 
     points you will receive. The default setting is level 1.

     Click on `exit` to end the game from the menu or hit `F4` at any time
     during the game. 

     Clicking on `high score` leads to the high scoring table.
     The alltime-highscore file will only accept one entry / player. 

     The program will keep your favorite settings.


STRATEGY

     The clue is that you have to combine your pieces so that they work
     together. Let`s take an example:

           O                                                    O   
           O         X means a piece of yours, O means          O
           X         an empty field and # is your opponent`s    X
     O O X O X O O   one. If you could reach a situation  O O X X X O O
           X         like this, you might put your              X
           O         next piece right in the middle.            O
           O         Now you have two rows of three             O
                     pieces with open ends. The computer 
                     can only put his piece at one open
                     end.

                                   O
                                   O
                                   X
                               # X X X O
                                   X
                                   X
                                   O

     Now you have the chance to place your piece to the row with the two
     open ends. Now it is a row of four pieces with open ends. This is 
     unbeatable, because if your opponent places his piece at one end, you 
     put yours at the other and reach `5 in a row`.

          O           There are lots of different              X
          X           situations like this.Find them,          X
          X           use them and you will be the             X
      # X X X O                  CHAMP!                    # X X X O
          X           But...you have to watch computer`s       X
          #           moves to block situations like           #
                      this.

INSTALLATION

     This program is made for DOS 3.0 or later.It will also run as
     a full screen DOS application under Windows 3.x, Windows 95 and 98,
     but not NT !!
     You should have a VGA Graphic card and a properly installed
     DOS (!!) mouse driver. The program provides soundblaster support. 

     The zip file contains the following files:

     get5_xx.exe       the run file
     get5_xx.dat       the graphics data
     get5.ico          an icon for installing the game under windows
     readme.txt        this file
     file_id.diz       file description for BBS systems
     vendinfo.diz      vendors info
     get5.hsc          the high score file
