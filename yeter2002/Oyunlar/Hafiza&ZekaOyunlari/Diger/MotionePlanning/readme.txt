		MOTION PLANNING
		===============

	    written by Mark Overmars

MOTION PLANNING is a program that, in the form
of a game, show you how difficult it is for a
robot to determine its motions amidst obstacles.
The program gives some insight in the type of
research done at the Department of Computer
Science, Utrecht University, in the area of
robot motion planning. The program is very easy
to use and help is provided at all places.

SYSTEM REQUIREMENTS
-------------------
A modern PC (preferably a Pentium) running
Windows'95, 98 or NT 4.0 or later is
required. After installation the program
uses about 1.5 megabytes disk space.

INSTALLING THE PROGRAM
----------------------
To install the program simply run SETUP.EXE.
This will start the InstallShield wizard that
will guide you through the installation. To
uninstall the program go to the Control Panel.
Select the icon Add/Remove Software and indicate
that you want to remove Motion Planning.
