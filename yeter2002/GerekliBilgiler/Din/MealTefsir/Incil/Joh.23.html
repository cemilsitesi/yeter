DON'T PANIC

File was not found in www.funet.fi

Possible reasons and suggested solutions:

You tried to list a directory in www.funet.fi using the http protocol
It has always been an unofficial unsupported feature which has now been disabled. But don't despair, we have now in pilot use the new official WWW.NIC.FUNET.FI server that does have much better, we hope, directory index, so please try it instead and fix possible references to www.funet.fi directories. The new name enables us to better distribute the load if necessary by separating the indexing and regular www service. If it fails you can report to with all possible details including exact time and URL at least and we'll try to see if we can fix it. Alternatively you can always use the good old and official FTP service at FTP.FUNET.FI.
There was a typo in the URL
Especially if you were looking for some handmade HTML pages and not automatic directory listings this may be true. If you can't figure it out try the suggestions presented for non-existent files or contact the relevant area administrators for information and of course tell them when and what URL you tried.
The file or directory really didn't exist
In this case you can again browse the http://WWW.NIC.FUNET.FI/pub/ tree for the right file or you can try searching the file via the Archie Database , Local filename search engine or NWI.FUNET.FI database which will soon contain also Dublin Core metadata from NIC.FUNET.FI
We made some error
Since we are humans and mostly overworked volunteers, that's quite possible. We apologize in advance and try to correct the problem. Contact the relevant area administrators for information and of course tell them when and what URL you tried.
